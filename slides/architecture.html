Architecture

A clean, modular, data-driven pipeline.

Layer 01
Data

Destinations, attractions, restaurants and certified routes — structured in SQLite, extensible to live tourism APIs.

Layer 02
Engine

TSP route optimizer, day scheduler, group-consensus scorer, and a self-improving recommender (taste profile + rating feedback).

Layer 03
Application

Streamlit UI in English with custom CSS animation, Lottie, and interactive Folium route maps.

Layer 04
Persistence

Trips, members, preferences, votes, comments, ratings and notifications — all stored and updated live.

DEPLOYED
Live on Streamlit Cloud · Code on GitHub · Reproducible with one command.
